# Contributing to DevGuide AI

Thank you for contributing to DevGuide AI!

## Development Guidelines
1. Ensure all code adheres to TypeScript strict mode.
2. Maintain clean separation of concerns between `database/`, `backend/`, and `src/frontend/`.
3. Verify changes with `npm run lint` and `npm run build` prior to submitting pull requests.
4. Ground all AI prompts in realistic AST structures with verified citations.
